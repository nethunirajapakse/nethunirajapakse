### [🔨 Rostra](https://github.com/nethunirajapakse/rostra)
An online auction platform where auctions, bidding and notifications run as separate services.

`Java 21` `Spring Boot` `Kafka` `PostgreSQL` `Docker`

Four services behind a Spring Cloud Gateway, reliable events with the **Transactional Outbox** pattern, and concurrent bidding handled with **optimistic locking** and **circuit breakers**.

`Spring Boot` `React` `TypeScript` `PostgreSQL`

Secured with **JWT cookie auth**, **CSRF protection** and **role-based access control**, deployed on Vercel, Render and Supabase.

</td>

### 🧠 Interlekt · On-Device Sinhala Small Language Model
A final-year research project building an offline Sinhala question-answering system for Android with retrieval-augmented generation and quantized language models.

`Python` `Kotlin` `llama.cpp` `Android NDK`

Converted SinLlama to GGUF, evaluated four quantization levels, and built a hybrid RAG pipeline plus a verification step that raised hallucination detection **F1 from 0.111 to 0.452**.
